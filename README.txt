Narayanganj Vision News Reporter Studio Android project (prototype)

Open this folder in Android Studio and allow Gradle sync. Build > Build APKs.

The native wrapper provides WebView camera/microphone permission handling for the camera HTML prototype.
Prototype limitations: online representative upload, secure admin accounts, cloud video inbox, and Facebook Live/RTMPS broadcasting are NOT implemented.
To use camera, install APK, allow Camera and Microphone permissions, then tap Camera Start.
